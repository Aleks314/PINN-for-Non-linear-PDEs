# PINN-for-Non-linear-PDEs
A project to build some PINNs to solve non-linear PDEs to be used for modelling of advection diffusion and later climate models.

As of right now I have manged to code up some individual neurons which were learning vectors, as well as a PINN which solves Poisson's equation with a constant source function and homogeneous Dirichlet BCs. I have also implemented a mini-batch SGD procedure to speed up computation.
